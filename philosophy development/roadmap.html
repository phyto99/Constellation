ASSERTED CONSTANTS — all scheduled for Phase 3 replacement
K_high
40
Refutation: if |predicted − actual| > 0.15 systematically for n ≤ 5 sessions, K is miscalibrated
→ Phase 3: fit K(n) as a curve
K_mid · K_low
20 · 10
Thresholds at n=5 and n=20 are arbitrary. The actual learning curve shape is unknown until measured.
→ Phase 3: fit threshold crossover points
elo_scale
400
Logistic scale factor. Refutation: if calibration scatter shows systematic S-curve curvature, scale is wrong.
→ Phase 2: BT transfer scores validate scale
r_bot
520
Bot Elo baseline. Refutation: if bot consistently ranks 1st or last across all sessions, baseline is wrong. Stored in every record for this reason.
→ Phase 1: empirical measurement from session outcomes
zpd_coeff
0.85
ZPD target = 0.85 × elo × decay. Refutation: if students at zpd_target show <50% win rate, ZPD is too aggressive; if >70%, too conservative.
→ Phase 3: fit against engagement retention
forgetting_τ
14d
Half-life of skill decay. Refutation: if Elo drop after session gap >14d doesn't match exp(−Δt/14), τ is wrong. Q4 specifically.
→ Phase 1: measurable after 60+ days of data
w_deficit
0.50
Priority weight: mode with lowest Elo. Refutation: if selecting highest-deficit mode doesn't produce faster overall Elo growth than alternatives.
→ Phase 3: fit weight triplet jointly
w_staleness
0.30
Priority weight: modes not seen recently. Refutation: if staleness-driven selection correlates with Elo drops (not gains), staleness is a noise signal.
→ Phase 3: fit weight triplet jointly
w_gap
0.20
Priority weight: BT gap signal. Currently always 0 (no BT data). Dormant until Phase 2. Weight itself must be fitted when gap data exists.
→ Phase 2: activate · Phase 3: fit
OPEN QUESTIONS — pre-registered in system-map.html
Q1
P0
Elo measures game performance, not cognitive skill. High Elo could mean memorized strategy, not transferred cognition.
Resolves Phase 2 → BT integration gives transfer_elo as independent measurement
Q2
P0
Announced INVERSION = wrong signal. Students behave differently when they know the rules are inverted (Hawthorne effect).
RESOLVED — silent_inv flag · Phase 0
Q3
P1
Mode non-orthogonality. QTY and FRT share spatial components. Student improvements may transfer across modes — currently treated as independent.
Resolves Phase 3 → covariance model fitted from cross-mode Elo correlations in Ledger
Q4
P1
Forgetting curve domain unknown. τ=14d is asserted. Real forgetting in spatial strategy games may differ from standard cognitive forgetting curves.
Resolves Phase 1→2 → measurable after 60+ days of session gap data in Ledger
Q5
P2
Social dimension absent. Whether a student performs differently in team compositions is untracked. Collaboration dynamics are invisible to the model.
Resolves Phase 1 → teacher team-composition tags; or accept as known limitation
Q6
P2
All parameters asserted. The system cannot justify any of its constants from evidence. It operates on priors it cannot yet defend.
Resolves Phase 3 → every constant replaced with posterior from Ledger data
Q7
P1
Gifted track incomplete. The Alpha application system is designed but not implemented. High-trajectory students have no accelerated path currently.
Resolves Phase 1 → Alpha system implementation · detective framework · student-observatory.html
Q8
P0 when BT
brain_metrics excluded. Direct cognitive measurement (working memory, inhibition, processing speed) currently absent. Game outcome is the only signal.
Resolves Phase 2 → BT integration: brain_metrics becomes a core Ledger field
