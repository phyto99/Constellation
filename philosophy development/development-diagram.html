Maximum Development Architecture — Complete System

Comfort and development are not mutually exclusive — but inversely correlated above a threshold. Below the threshold: no signal, no development (student overwhelmed or disengaged). Above it: discomfort is the mechanism. The system targets minimum comfort consistent with clean signal — not maximum comfort.

Template Constraint Depth — Developmental Ranking by Mode

Within a selected mode, the most developmental template has the most locked axes. Locked axes are the cognitive constraint — they prevent the student from bypassing the cognitive target through an alternative strategy. Free axes scale difficulty without changing what's being trained. Top of each column = most developmental template for that mode.
⊗ locked axis — cognitive constraint, must not change ⊕ free axis — difficulty lever only Top-ranked template = system default for max development

Spectrum Zone Selection — Mode Exposure × Last Outcome

The existing system selects spectrum zone from last outcome only. Maximum development requires a second axis: mode exposure depth. A student new to a mode needs ECHO (familiarity before variation). A mode-mature student needs PARALLEL or SHIFTING (same cognitive target, new surface form — forces abstraction). RADICAL is only developmental when the mode is mastered and outcome confirms it.

Zone Reference

Overlay Gate — When INVERSION and ITHKUIL Are Developmental vs Noise

INVERSION is only developmental when applied to a mastered mode. The mechanism: student notices their heuristics are failing and adapts. This requires stable heuristics to exist first. Applied to an unmastered mode: the student cannot recognize what changed because they had no working model. Overlay must challenge a built structure, not a void.

The Heuristic Prerequisite

INVERSION's developmental mechanism is productive destruction: the student has built a working model, the overlay invalidates it, and the student must build a new one. That cycle is the cognitive flexibility training.

Without the prior model there is nothing to destroy — the student is already operating without stable strategy. INVERSION applied here produces noise signals and demoralization, not adaptation speed signals.
