Open Questions — Every Unresolved Problem

● CRITICAL — affects every metric
Q1: Elo measures game performance, not cognitive skill
Currentmode_elo[6] updated from competitive session rank. Measures how well the student performs in Constellation relative to peers.
ProblemA student who memorizes FORTRESS opening sequences has high FRT Elo. A student who understands graph connectivity but plays inconsistently has lower FRT Elo. These are different cognitive states. The system cannot tell them apart.
ResolutionMaintain parallel transfer_elo[mode] from brief out-of-game cognitive tasks administered periodically. The gap between game_elo and transfer_elo is the most diagnostic signal in the system. Wide gap = game knowledge, not cognitive development. BT system provides this.
PriorityP0 — this corrupts the objective function until resolved
● CRITICAL — fundamental signal contamination
Q2: INVERSION announces itself — the wrong signal
CurrentTerminal always announces INVERSION: "The reward structure has been altered." Student knows a reversal is happening before it starts.
ProblemGenuine reversal learning — the cognitive skill being trained — is adapting to a change you did not know was coming. "Adapt to announced change" is cognitively easier than "detect and adapt to unannounced change." The system is measuring the easier skill and calling it cognitive flexibility.
ResolutionSome INVERSION sessions should be silent. Terminal says nothing about an overlay. Student discovers the reversal from score feedback alone. The strategy_shift_speed signal from a silent INVERSION is the clean reversal learning measure. Announced INVERSION remains as an introduction; silent INVERSION is the advanced form.
PriorityP0 — corrupts the INV mode signal quality
◆ STRUCTURAL — affects mode isolation claims
Q3: The 6 modes are not cognitively orthogonal
CurrentSystem treats 6 modes as independent cognitive dimensions. Session selection and Elo are computed per-mode as if modes don't interact.
ProblemFORTRESS (hq×500, dest×−200) requires inhibitory control — resisting the impulse to destroy when destroying is costly. Inhibitory control is DESTRUCTION's primary cognitive target. Optimal FORTRESS play uses DST's cognitive skill. The modes overlap. A student's FRT Elo incorporates their inhibitory control capacity.
ResolutionReplace the independence assumption with a covariance model: mode_elo[6] as a correlated multivariate, not 6 independent scalars. The correlation structure reveals which modes are transferring to each other. A student high in FRT who improves in DST faster than expected is demonstrating the connection. BT system can map the true cognitive factor structure.
PriorityP1 — affects analysis accuracy but not catastrophically
◆ STRUCTURAL — affects difficulty calibration
Q4: Forgetting curve wrong domain — Ebbinghaus is verbal memory
CurrentForgetting decay: d_adjusted = d_base × exp(−τ/14 days). 14-day half-life borrowed from Ebbinghaus forgetting curve literature on verbal recall.
ProblemStrategic and procedural skills decay significantly more slowly than verbal memory. Motor learning (a closer analogue to competitive game strategy) can persist for months without practice. The 14-day assumption may be dramatically wrong, causing the system to lower difficulty too aggressively when students return after breaks.
ResolutionMeasure empirically: track Elo on mode return as function of days elapsed. Fit the exponential decay. Read off the true half-life for this student population and this game type. Initial guess: 30–60 days, not 14. BT system longitudinal data can cross-validate.
PriorityP1 — measurable and correctable with data
◉ STRUCTURAL BLIND SPOT — unmodeled dimension
Q5: The social dimension is entirely absent
CurrentSystem measures what the student does: star claims, HQ connections, steal rates, score rank. No measurement of social-emotional behavior.
ProblemThe game is multiplayer. For younger students especially, the most important developmental outcomes may be: how do they respond to losing in front of peers? Do they support or undermine teammates? Do they disengage under pressure or adapt? These are not measured. The system is cognitively complete and socially blind.
ResolutionOption A: Accept the limitation — the system develops cognitive skills, and social-emotional development happens in the social context around the game, not within the system. Option B: Add participation/engagement signals (reconnection rate, session completion rate, cooperative behavior tags from teacher). Option B requires teacher input. Option A is consistent with the system's scope.
PriorityP2 — critical for younger students, manageable for teen primary audience
◉ MEASUREMENT — proxy validity uncertain
Q6: All parameters are asserted, none validated for this context
Parametersdifficulty coefficient 0.85 · overlay probability 0.25 · hypercube window 6 · elo_weight exponent 0.7 · flow zone 25–75th pct · budget thresholds 0/1/6/20/50
ProblemEvery parameter is derived from theory or educated guessing. They are probably directionally correct. They are almost certainly wrong in magnitude for this specific student population, game type, and cultural context.
ResolutionPhase 2 instrumentation: log every parameter value used alongside the outcome it produced (ΔElo_velocity). Regress outcome on parameter values. The coefficients that maximize ΔElo_velocity are the correct ones. This is a 50-session data collection project, not a research program.
PriorityP2 — directional correctness sufficient for Phase 1
◆ DESIGN — gifted track incomplete
Q7: Gifted detection threshold is guessed, not calibrated
CurrentGifted detection: elo_velocity ≥ 2 SD above cohort mean in sessions 1–5. Accelerate to INVERSION at session 3 instead of session 6.
ProblemThe 2 SD threshold and the session-3 INVERSION trigger are guesses. More critically: the gifted track is defined by what to accelerate, not by what gifted students specifically need that standard students don't. The key claim — gifted students need calibrated failure, not accelerated success — is unvalidated.
ResolutionRun two gifted student cohorts: one accelerated, one standard calibration at higher difficulty. Measure which produces faster transfer_elo improvement and better outcomes on the Alpha application quality metric. BT system can provide pre/post cognitive benchmarks.
PriorityP1 — gifted students are most likely to plateau if not correctly handled

Brain Training Bridge — How BT and Constellation Connect

THE KEY INSIGHT
Constellation measures how students perform in Constellation. The brain training system measures cognitive capacity independent of any game. These are different things — and together they are the complete picture. Constellation without BT: we know the student performed better at the game, but not whether they got cognitively smarter. BT without Constellation: we know cognitive scores improved, but not through what mechanism. Together: we know both, and we can measure whether game training is producing genuine cognitive development.

The Gap Signal

The most important measurement in the combined system is not game_elo or BT_score — it is the gap between them. A student with high game FRT Elo and low BT executive function score has learned Constellation FORTRESS strategy without developing the underlying cognitive capacity. The gap is the diagnostic. The system should detect and respond to it.
Gap patternInterpretationSystem response
game_elo ↑↑
BT_score →		 Game optimization without cognitive transfer. Student has learned Constellation, not the skill. Increase INVERSION frequency. Reduce ECHO. Force template rotation to prevent memorization.
game_elo →
BT_score ↑↑		 Cognitive development not reflected in game performance. Student is developing but the game isn't capturing it. Investigate: is the difficulty calibration wrong? Is there a mode mismatch? May need new mode templates.
game_elo ↑
BT_score ↑		 Transfer occurring. Game training producing genuine cognitive development. This is the target state. Continue current trajectory. System is working.
game_elo ↓
BT_score ↑		 Cognitive development may be outpacing the game's ability to challenge the student. Game too easy at cognitive level. Advance to design challenge track. Consider new game introduction.
When BT is integrated: brain_metrics changes from EXCLUDE to the most important variable in the system. transfer_elo[mode] = BT_score[corresponding_dimension]. The gap measurement becomes the primary signal driving session selection, not raw game Elo.

The philosophical question that must be answered before Phase 2

What is the external validation target?

The system develops 6 cognitive skills through game play. BT provides measures of those 6 cognitive skills independent of the game. But what counts as evidence that a student has genuinely developed?

Options:
A. BT score improvement on the 6 corresponding dimensions
B. Improved performance on novel strategy games not trained on
C. Improved academic performance in relevant subjects
D. Teacher-assessed improvement in strategic thinking quality
E. Some combination

This choice changes everything. Option A makes BT the ground truth and Constellation the training tool. Option C makes academic outcomes the ground truth and both BT and Constellation as training tools. Option D reintroduces subjectivity. The system cannot be "objectively perfect" until this question has a decided answer.
The system as currently designed is complete for Option A. If BT cognitive scores are the validation target, the architecture described across these documents is the correct architecture. Every component is in the right place. The Phase 0–2 build order above produces a system that can demonstrate: game training → BT score improvement → cognitive development validated. This is the strongest version of the claim the system can make without long-term longitudinal studies.
