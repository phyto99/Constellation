The Axiom — Record Observations, Not Interpretations

0
THE EVIDENCE AXIOM
Every measurement event is recorded once, raw, with full provenance, forever. Every interpretation — category, score, diagnosis, validation verdict — is a view computed over those records. Views are cheap, disposable, and recomputable. Records are permanent. Categories are views, not containers. No exceptions.

This is the system's answer to a question that will otherwise recur forever: which category does this observation belong to? Does a blackhole chain count as DESTRUCTION signal or SPATIAL signal? Is teacher feedback validation evidence or engagement evidence? Is academic improvement the ground truth or a side effect? Every one of these questions is a fork where choosing wrong loses data permanently — and choosing at all is unnecessary. The conundrum dissolves when storage and interpretation are separated: store the event with every applicable tag, defer the categorization to read time, and recompute freely as understanding improves.

The Two Inclusion Criteria — Ledger vs State

The variable audit (system-complete.html) says: include variable V in the state iff I(accuracy; V | existing) > ε. That criterion is correct — for the state. It was never a rule about what to record. Conflating them is the error this document exists to prevent.

The state is derived from the ledger as a view. mode_elo[6] is a fold over rank observations. elo_velocity[6] is its derivative. When a parameter changes — when the forgetting half-life is corrected from 14 days to 40 — the entire Elo history can be recomputed from raw ranks under the new parameter. A system that stores only the state can never correct its own past.

What This Resolves

brain_metrics was never wrong to exclude — it was wrong to not record. The Q8 decision (EXCLUDE until validated) was correct at the state level and destructive at the ledger level. Under the evidence axiom, brain metrics are recorded from day one as low-confidence observations in their own channel. When the BT bridge validates them, the entire history is already there — the mutual information measurement Q8 requires runs over years of data the day the question is asked, not starting from zero. Recording is not endorsement. The ledger has no opinion.

The Resolution of the Validation Question

system-map.html names "the philosophical question that must be answered before Phase 2": what counts as evidence that a student has genuinely developed — BT scores (A), novel-game transfer (B), academic outcomes (C), teacher assessment (D), or some combination (E)? It states: "The system cannot be objectively perfect until this question has a decided answer."

The question is not answered. It is dissolved. Choosing a ground truth in advance is the same error as choosing a category at write time — it privileges one channel before the data exists to justify the privilege. The evidence engine tracks all five paths simultaneously as independent channels. Ground truth is not an input to the architecture; it is an output: the channel structure that emerges from measured mutual information between channels. If BT scores predict novel-game transfer and academic outcomes, BT earns ground-truth weight. If teacher assessment adds no information beyond game signals, it loses weight. The system does not assert what development means — it measures which definitions of development agree with each other, and reports the agreement structure. Option E was always the answer, but E is not a compromise between A–D. E is the corroboration matrix.

This is the same move the system already makes everywhere else, applied to itself one more time: the multiplier doesn't choose a cognitive target — it parameterizes all of them. The compiler doesn't choose a curriculum — it derives one per student per session. The evidence engine doesn't choose a ground truth — it maintains all candidates and lets accumulated mutual information decide. Same principle, one level up. The recursion is the proof of fit.

Why This Is the Flexible System — Permanently

New discovery

A 7th cognitive mode is proposed. A new signal type is found in round-timing data. A new game joins. Nothing changes in the ledger. A new tag vocabulary entry is minted; new views are defined; old records are reinterpreted under the new vocabulary for free, because they were stored raw.

New conundrum

An observation fits two categories, or none. No decision is forced. Multi-tag it, file a boundary case, continue. Categories adjust to evidence; evidence is never trimmed to fit categories. The protocol is on the Conundrum tab. It is the same protocol for every future situation, which is what makes it perfect: it does not need to anticipate the situation.

New question

"Does forgetting differ by mode?" "Do gifted students plateau differently?" "Did the 0.85 coefficient help?" Every question becomes a query. If the ledger is complete, the answer is a view over existing records. The library of cognitive reaction data (Reaction Library tab) is this property at full scale.

Schema — Four Record Types, One Discipline

1. Observation — the atom

Observation = { id, t ← identity, timestamp (absolute) subject: {student, cohort, team?} context: { game, session_id, round?, mode, template, overlay, config_hash, ← exact multiplier config params_version ← which parameter set was live } channel: GAME | BT | NOVEL | ACADEMIC | TEACHER | PEER | SELF | SYSTEM signal: {name, value, unit} ← OPEN vocabulary tags: [..] ← multi-tag, never single quality: {noise, coverage, purity_flags[]} }
Open vocabulary: signal.name is not an enum. hq_connection_round, steal_rate_2nd_half, strategy_shift_speed, bt_inhibitory_score, teacher_tag_supportive — all legal, including names that do not exist yet. A closed vocabulary is a category decision made at write time, which the axiom forbids.

Purity flags travel with the data: an INV observation from an announced INVERSION session carries purity: [announced_overlay] permanently (Q2). Any view computing cognitive flexibility sees the contamination and can include, exclude, or down-weight it. The flag is recorded once; the judgment is recomputed forever.

2. Claim — the interpretation

Claim = { id, statement ← "INV flexibility improving" dimension ← mode | engagement | social | NEW support: {channel → [observation ids]} corroboration: k of n ← independent channels agreeing status: ASSERTED → INSTRUMENTED → MEASURED → CORROBORATED → VALIDATED | REFUTED }

3. Parameter — the hypothesis

Parameter = { name, value, version status: ASSERTED | LEARNED rationale ← why this value, source outcomes: [observation ids]← logged at every use }

4. View — the disposable lens

View = pure_fn(Ledger, Params, Vocab) → display mode_elo[6] = fold(rank obs, elo_params) gap[mode] = view(GAME) − view(BT) corroboration_mtx = agreement(channels × dims) student_panel = compose(all of the above)
Views own no data. Deleting every view loses nothing. This is what makes the system a living organism rather than a structure: the skeleton (ledger) is permanent; the organs (views) regenerate.

The Epistemic Lifecycle — Every Claim Walks the Same Path

Nothing skips stages and nothing is exempt. "Maximize E[KL] per session" is itself a claim, currently at MEASURED (it demonstrably selects sessions; its developmental superiority is not yet corroborated by a second channel). The 6-mode structure is a claim. The zone vocabulary's community effect is a claim. The engine applies to the system's own philosophy with the same discipline it applies to a student's steal rate. A system that audits everything except itself is not objective — it is merely strict.
REFUTED is a success state. A refuted claim with full provenance is worth more than an unexamined assertion. When the 14-day forgetting half-life is refuted by return-Elo data, the system gets better — and the refutation is itself recorded, so the same wrong value is never asserted twice. The only failure state in this architecture is an event that was not recorded.

The Generalized Gap Signal

system-map.html defines the gap signal as game_elo − transfer_elo per mode. That is one instance of the general form:

gap(d, c₁, c₂) = view(d | c₁) − view(d | c₂) for any dimension d, any channel pair (c₁, c₂)
Gap instanceWhat divergence means
GAME − BTGame knowledge without cognitive transfer (the original Q1 gap)
GAME − NOVELConstellation-specific optimization — the medium has gone opaque
BT − ACADEMICCognitive gains not reaching the classroom — mapping or transfer-distance problem
SELF − GAMEUnderstanding outruns performance: design-track candidate. Or inverse: performing without understanding — Alpha not yet.
TEACHER − allTeacher channel adds no information → reduce its learned weight; or teacher sees what nothing else sees (Q5 social) → its unique signal is exactly there
Corroboration rule: a claim's strength is the number of independent channels supporting it, not the volume of evidence within one channel. A thousand game sessions are one witness. One witness, however eloquent, is ASSERTED→MEASURED at best. CORROBORATED requires a second independent channel; VALIDATED requires the corroboration to survive a pre-registered prediction. SYSTEM-channel inferences never count — the system cannot corroborate itself.

The Conundrum Protocol — What To Do Every Time Categories Fail

This protocol exists because the question "which category?" will arise again, in a form not anticipated here, after every new discovery. The protocol does not enumerate cases. It is one rule applied identically to all of them, which is the only way a protocol survives contact with situations its authors did not imagine.

Worked: the blackhole chain

SYNTHESIS insight #2: blackhole chains demonstrate DESTRUCTION and SPATIAL reasoning. The old system filed it as DST and lost the SPT signal.

Protocol: record once, tags:[dst, spt, composite]. Views that compute DST Elo and SPT inference both see it. No committee, no redesign. When enough composite signals accumulate, they become the empirical basis for the Q3 covariance model — the boundary cases are the dataset.

Worked: the social dimension

Q5 framed social-emotional behavior as Option A (out of scope) vs Option B (add teacher tags) — a category decision.

Protocol: reconnection rate, session completion, teammate-support tags are cheap to record. Record them in TEACHER and GAME channels under a social dimension with no claims attached. The scope decision is deferred to the moment evidence forces it — which is when it stops being philosophical and becomes empirical.

Worked: a signal with no name

A student pauses 11 seconds before every move that precedes a strategy shift. No existing signal type covers pre-move latency.

Protocol: mint pre_move_latency on the spot (open vocabulary), record, file a boundary case. If it recurs across students, it graduates to a candidate state variable and enters the variable audit. The audit governs promotion to the state — never permission to record.

The protocol is the design philosophy applied to epistemics. "Every visual choice must do semantic work" becomes "every category must do inferential work." A category that forces information loss at write time is decoration with a cost. The ledger refuses it the same way the documents refuse unearned color.

Parameter Registry — Every Hardcoded Value Is a Hypothesis On Trial

Every parameter is versioned, carries its rationale, and logs an observation at every use — {params_version} in the observation context is the join key. The regression that replaces [ASSERTED] with [LEARNED] is a standing view over the ledger, not a research project to be scheduled.

The refutation condition is mandatory and written in advance. A hypothesis that cannot say what would refute it is not a hypothesis — it is a setting. Pre-registration is what separates "the data will decide" from "we will rationalize whatever happens." The registry holds the conditions; the views check them continuously; a parameter whose condition fires is flagged in the Observatory the same way a student anomaly is.
Note the last row. The evidence engine's own thresholds are registered in the registry they define. This recursion is deliberate and load-bearing: the moment the engine exempts itself, it becomes the one unexamined assertion in a system whose entire identity is that nothing is unexamined.

The Reaction Library — Cognitive Chemistry, Recorded Completely

A session is a reaction: a student state (reagents) under a session configuration (conditions) yields a state change plus emitted signals (products). The objective of the ledger, at full scale, is the complete reaction record — every student × training-method interaction the program has ever run, queryable. Not a metaphor: the record below is the literal join of existing record types.

Reaction = { reagents: S(t) ← full 18-dim state + age tier + track + trajectory stage conditions: C, θ ← mode, template, overlay, difficulty, map seed, team composition, bot archetypes, params_version products: ΔS, [obs] ← state delta + every observation emitted, all channels yield: E[KL] realized vs predicted ← did the session inform as expected? }

Yield — the session grading itself

Predicted information gain is recorded before the session (it is why the session was selected). Realized gain is computed after. The scatter of predicted vs realized is the system's calibration curve — drift from the diagonal is the earliest possible warning that the model of the students no longer matches the students.

What "best library of cognitive data" actually requires

Not volume. Completeness of provenance. A reaction record is research-grade when an outsider could re-derive every conclusion from the raw records alone: which parameters were live, which overlay was announced, which channel produced which number, what the system predicted before it knew the outcome. Every record in this architecture carries that provenance by construction — not by policy, which decays, but by schema, which doesn't. The library is not a future project. It is what the ledger is, the day recording starts, growing one fully-described reaction per session forever.
