Elo Update Rule ASSERTED
// Applied after every session, for the mode active this session E = 1 / (1 + 10^((R_bot − R_student) / 400)) S = session_rank_percentile // 0.0–1.0 K = 40 if n_in_mode ≤ 5 K = 20 if n_in_mode ≤ 20 K = 10 if n_in_mode > 20 ΔElo = K × (S − E) new_elo[m] = old_elo[m] + ΔElo
Refutation condition
If Elo residuals (predicted rank − actual rank) show systematic bias > 0.10 over ≥ 30 sessions per mode: refute K schedule, refit from data. Phase 3 replaces Elo entirely with a fitted function over the full config × outcome history in Layer 0.
Elo Velocity ASSERTED window=3
// Rate of change over last 3 sessions in this mode velocity[m] = (elo[m] at session N) − (elo[m] at session N−3) / 3 // Undefined if n_in_mode < 4. High variance if n_in_mode < 8.
Refutation condition
If window=3 produces higher autocorrelation than window=5 in held-out prediction: expand window. Velocity is a proxy for learning rate — the proxy's accuracy is itself measurable.
ZPD Target ASSERTED coeff=0.85
// Target difficulty for next session in mode m decay = exp(−sessions_since[m] / 14) zpd_target[m] = elo[m] × 0.85 × decay
Refutation condition
If sessions with difficulty at 0.85×Elo produce worse Δelo_velocity than sessions at 0.90× or 0.80×: refute 0.85. If forgetting curve fit over return-Elo data produces τ outside [10d, 18d]: refute τ=14d (expected to refute toward 30–60d).
Confidence Interval ASSERTED
// Uncertainty on elo[m] estimate se = std(outcomes_in_mode) / sqrt(n_in_mode) ci_95 = elo[m] ± 1.96 × se × 400 // Wide CI: few sessions, high outcome variance // Narrow CI: many sessions, consistent outcomes
Phase 3 replacement
Bayesian posterior over skill estimate, updated after every session. The ±CI is then a credible interval from the posterior, not a frequentist approximation. Requires ≥ 50 sessions per student to fit reliably.
